# 7. SEARCH INTENT MODEL

Classify keywords/pages as:

## Transactional

User is close to purchasing.

Examples:

couples budget template
couples budget spreadsheet
budget spreadsheet for couples
couples budget planner

Best destination:
Product page.

---

## Commercial Investigation

User is comparing possible solutions.

Examples:

best budget app for couples
budgeting apps for couples
budget app for couples
budgeting software for couples

Best destination:
High-quality comparison content.

Do NOT pretend Togetherly is an app.

Togetherly can be presented accurately as a Google Sheets alternative.

---

## Informational

User wants to solve or understand a problem.

Examples:

how to budget as a couple
how should couples split expenses
how to split bills with different incomes
budget categories for couples

Best destination:
Blog article or tool.

---

## Tool Intent

User wants an immediate calculation.

Examples:

couples expense split calculator
split bills based on income calculator
proportional expense calculator

Best destination:
Interactive tool.
