# TOGETHERLY — SEO CONTENT ENGINE

This section defines how Togetherly should research, plan, write, publish,
interlink, and expand SEO content.

The objective is to build long-term topical authority around couples money
management and generate qualified traffic for:

1. Togetherly's free tools
2. Togetherly's email notification list
3. Togetherly's Couples Money Planner
4. Future validated digital products

The objective is NOT to generate the largest possible number of articles.

The objective is:

MAXIMUM RELEVANT SEARCH-QUERY COVERAGE
+
MINIMUM KEYWORD CANNIBALIZATION
+
HIGH SEARCH INTENT SATISFACTION
+
STRONG INTERNAL LINKING
+
PRODUCT RELEVANCE

---

# 1. CORE SEO RULE

ONE DISTINCT SEARCH INTENT → ONE PRIMARY PAGE.

Do not create separate articles merely because keyword wording differs.

Example:

"how to manage finances as a couple"
"managing finances as a couple"
"handling finances as a couple"
"how couples manage finances"
"best way to manage finances as a couple"

These belong primarily to ONE strong page:

/blog/how-to-manage-finances-as-a-couple

That article should naturally cover the entire semantic keyword family.

Do not create five near-duplicate articles.

# 18. ARTICLE WRITING RULES

Every article must be written primarily for the person who searched the query.

Before writing, determine:

SEARCH QUERY
→ USER PROBLEM
→ DESIRED ANSWER
→ SEARCH INTENT
→ BEST PAGE FORMAT
→ NEXT LOGICAL ACTION

Do not begin with generic filler such as:

"Money is an important part of every relationship."

Get to the user's problem quickly.

For example:

Query:
how to split bills based on income

The article should quickly explain the formula and give an example.

Do not force the user through 1,000 words before answering the question.

---

# 19. ARTICLE STRUCTURE

Structure should vary according to intent.

Do NOT mechanically use the same template for every article.

A typical informational article may contain:

Comparison table where genuinely useful

Step-by-step process

Common mistakes

FAQ

Relevant tool CTA

Product CTA

The content must feel written for that specific query rather than generated
from a universal SEO template.

# 20. KEYWORD USAGE

Primary keyword should normally appear naturally in:

- SEO title
- meta description where appropriate
- H1 or close semantic equivalent
- introduction
- at least one useful heading where natural
- body content
- image alt text only when accurately describing the image

Secondary keywords should be distributed naturally.

DO NOT:

- repeat exact-match phrases unnaturally
- stuff keywords into every heading
- create awkward sentences for SEO
- list keyword variants inside paragraphs
- hide keywords
- generate pages purely for variants

Use semantic coverage instead.

# 37. CONTENT EXPANSION RULE

Do NOT decide the next 100 articles upfront.

Start with validated clusters.

Then use Search Console.

Example:

Existing article begins receiving impressions for:

"how to split rent when one partner earns more"

If the intent is adequately answered by:

/blog/split-bills-based-on-income

→ improve that article.

Do NOT automatically create a new page.

If Search Console reveals a substantially different recurring problem that the
existing article cannot satisfy:

→ research it
→ assign a new intent
→ create a new page if justified.
